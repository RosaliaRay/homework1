## Описание программы

Консольная программа на языке C для ввода и анализа одномерного массива
целых чисел. Программа:

- запрашивает размер массива (1..100) с проверкой корректности;
- вводит элементы массива;
- выводит исходный массив;
- находит минимальный и максимальный элементы и их первые индексы;
- вычисляет сумму и среднее арифметическое;
- подсчитывает положительные, отрицательные, нулевые, чётные и нечётные элементы;
- запрашивает диапазон [a, b] и выводит элементы, попавшие в него;
- **индивидуальное задание (вариант 11):** формирует новый массив из элементов,
  принадлежащих диапазону [a, b], сохраняя исходный порядок.

## Команда компиляции и запуска

    gcc main.c -Wall -Wextra -Wpedantic -std=c11 -o homework1
    .\homework1.exe    # Windows

## Входные данные

1. Размер массива `n` — целое число от 1 до 100.
2. `n` целых чисел — элементы массива.
3. Два целых числа `a` и `b` — границы диапазона (если `a > b`, они автоматически
   меняются местами).

## Выходные данные

- исходный массив;
- минимум, максимум и их первые индексы;
- сумма и среднее арифметическое;
- количество положительных / отрицательных / нулевых;
- количество чётных / нечётных;
- элементы, попавшие в диапазон [a, b];
- новый массив из элементов диапазона [a, b] и его характеристики.

| `findMaxIndex` | индекс первого максимального элемента |

| `countSigns` | количество положительных / отрицательных / нулевых |
| `countParity` | количество чётных / нечётных |
| `printRange` | печать элементов, попавших в [a, b] |
| `performIndividualTask` | вариант 11: новый массив из диапазона [a, b] |
